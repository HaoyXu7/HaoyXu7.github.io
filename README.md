# Haoyang Xu · 许浩阳

武汉大学计算机学院个人学术主页。

纯静态 HTML/CSS，无需构建。编辑 `index.html` 修改内容，编辑 `style.css` 修改样式，`assets/` 包含照片及论文首页缩略图。

## GitHub Pages

将本目录推送到个人主页仓库 `<username>.github.io`，在 Settings → Pages 中选择 Deploy from a branch，分支 main、目录 / (root)。

本地预览：`python3 -m http.server 8080`。

论文链接来自 arXiv；教育与履历来自本人简历。
